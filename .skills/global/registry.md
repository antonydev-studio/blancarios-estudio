# Global Skill Registry — Barber BR

## How to use

Before implementing anything, search this registry for matching skills.
Load the skill file, follow the recipe, adapt to context.

## Project Skills — `.skills/project/`

|-------|----------|
| `vercel-handler.md` | creating any `api/*/[...path].js` file |
| `mongodb-connection.md` | writing `lib/mongoose.js` or any DB connection |
| `api-route-pattern.md` | deciding route order inside handler |
| `appointment-conflict.md` | implementing time-slot conflict detection |
| `auth-flow.md` | building auth endpoints or middleware |
| `react-component.md` | creating any React component |
| `tailwind-patterns.md` | building UI with Tailwind CSS 4 |
| `async-patterns.md` | any async controller or service function |
| `pnpm-workflow.md` | any CLI operation in this project |
